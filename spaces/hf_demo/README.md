# Laya-as-a-Judge v1.1.0 ⚡⚖️

Interactive Hugging Face Space for **[`radeksixi/laya-as-judge`](https://github.com/radeksixi/laya-as-judge)** (Apache-2.0) — the zero-output-token Decision, Judge, Ecosystem Drop-In, and Hybrid Agent Governance (`COMMIT / FALLBACK / ABSTAIN / BLOCK`) API built alongside [Sixi Lab R&D](https://sixi.ai) / [Sixi Assure](https://sixi.ai/en/assure/).

- **Instant Static Playground (`index.html`):** Runs zero-latency interactive demos in the browser with no cold starts.
- **Full Local Python / Gradio App (`app.py`):** Run locally via `pip install gradio laya-as-judge && python spaces/hf_demo/app.py` or launch the FastAPI server via `laya-judge serve --profile rtx-16gb`.
